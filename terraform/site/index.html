Served straight from Amazon S3

This page is three objects in an S3 bucket with static website hosting switched on. There is no server to patch.

  • Public: this page, the error page and one stylesheet.
  • Private: documents, images, logs and backups, in a separate bucket that blocks all public access.
  • Databases: Amazon RDS for PostgreSQL for orders, Amazon DynamoDB for shopping carts.
